# todo-list
# 📝 To-Do List Application — React.js

A simple and efficient **task management application** built using **React.js**, enabling users to add, update, delete and organize daily tasks with a clean UI.

---

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- ✔ Mark tasks as completed
- 📂 Filter tasks (All / Completed / Pending)
- 📱 Fully responsive UI (Mobile-friendly)
- ♻ Uses React Hooks for state management

---

## 🛠️ Tech Stack

| Technology | Used For |
|-----------|----------|
| React.js | Frontend UI |
| CSS3 | Styling & layout |
| JavaScript (ES6+) | Logic & Interactivity |
